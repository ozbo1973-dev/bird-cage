# BRD-115 — Clean up color theme to make the full app use a theme.

## Summary

Consolidate 228 hardcoded color values across 21 CSS module files into a centralized theme using CSS custom properties, enabling consistent branding and easy color adjustments throughout the application.

## Implementation Steps

1. **Define color theme as CSS custom properties in `globals.css`**
   - Add primary colors: `--color-primary-blue: #209dd7`, `--color-primary-purple: #753991`, `--color-primary-yellow: #ecad0a`, `--color-primary-navy: #032147`
   - Add secondary/utility colors: `--color-text-gray: #888888`, `--color-text-dark: #032147`, `--color-text-light: #666`, `--color-border-light: #ddd`, `--color-border-medium: #e8e8e4`, `--color-border-light-gray: #eeeeea`
   - Add backgrounds: `--color-bg-white: #ffffff`, `--color-bg-light: #f5f5f0`, `--color-bg-lighter: #fafaf8`, `--color-bg-lightest: #f9f9f7`
   - Add accent backgrounds: `--color-bg-blue-light: #e8f4fb`, `--color-bg-yellow-light: #fef9e6`, `--color-bg-purple-light: #f3eaf7`
   - Add error and other utilities: `--color-error: #c0392b`, `--color-error-light: #fde8e8`, `--color-success: #2c6e49`, `--color-success-hover: #245a3b`, `--color-footer-dark: #021836`

2. **Update `AuthForm.module.css` (10 hardcoded colors)**
   - Replace `#444` → `var(--color-text-dark-secondary)`
   - Replace `#209dd7` → `var(--color-primary-blue)`
   - Replace `#c0392b` → `var(--color-error)`
   - Replace `#753991` → `var(--color-primary-purple)`
   - Replace `#888888` → `var(--color-text-gray)`
   - Replace `#ddd` and `#032147` → appropriate CSS variables

3. **Update `EventForm.module.css` (33 hardcoded colors)**
   - Replace all `#209dd7` → `var(--color-primary-blue)`
   - Replace all `#753991` → `var(--color-primary-purple)`
   - Replace all `#c0392b` → `var(--color-error)`
   - Replace border colors (`#ddd`, `#e8e8e4`, `#f0f0ea`) → appropriate CSS variables
   - Replace background colors (`#fafaf8`, `white`) → CSS variables
   - Replace text colors (`#444`, `#555`) → CSS variables

4. **Update `dashboard/page.module.css` (8 hardcoded colors)**
   - Replace `#2c6e49` → `var(--color-success)`
   - Replace `#245a3b` → `var(--color-success-hover)`
   - Replace `#e8e8e4` and `#ddd` → CSS variables for borders
   - Replace `#666`, `#444` → text color CSS variables

5. **Update remaining CSS module files (172 colors across 17 files)**
   - `AddBirdForm.module.css`: replace 20 colors
   - `BirdEditForm.module.css`: replace 20 colors
   - `BirdActions.module.css`: replace 7 colors (`#209dd7`, `#c0392b`)
   - `EventActions.module.css`: replace 7 colors
   - `ConfirmDialog.module.css`: replace 6 colors
   - `DashboardTabs.module.css`: replace 20 colors
   - `BirdChatWidget.module.css`: replace 15 colors
   - `landing.module.css`: replace 47 colors
   - `login/page.module.css`, `page.module.css`, `verify-email/VerifyEmailClient.module.css`, `DragDropZone.module.css`, `LogoutButton.module.css`, `MapDialog.module.css`, and other module files

6. **Update inline styles in `src/app/page.tsx`**
   - Replace inline `style={{ background: "#e8f4fb" }}` → `style={{ background: "var(--color-bg-blue-light)" }}`
   - Replace inline `color="#209dd7"` in Lucide icon colors → use CSS classes or pass as CSS variables

7. **Add secondary color variables for text variations**
   - Add `--color-text-muted: #555`, `--color-text-secondary: #444`, `--color-text-placeholder: #888888`
   - Add hover state colors for buttons: `--color-button-hover-opacity: 0.85`, `--color-button-disabled-opacity: 0.6`

8. **Test all pages for visual consistency**
   - Verify landing page (public) renders correctly
   - Verify login and signup pages use theme colors
   - Verify dashboard and event/bird edit pages maintain styling
   - Verify dialog, action buttons, and forms display with proper colors

## Technical Notes

- CSS custom properties will be defined in `:root` selector in `globals.css` for global scope
- All 228 hardcoded colors will be systematically replaced, maintaining exact visual appearance
- No layout or spacing changes required—only color consolidation
- CSS variables will follow naming convention: `--color-[category]-[shade]` (e.g., `--color-primary-blue`, `--color-bg-light`)
- Future theme changes can be made by updating the 20–25 CSS variables in `globals.css`
- No JavaScript changes needed; purely CSS-based theming

## Acceptance Criteria

- [ ] CSS custom properties defined in `globals.css` for all colors used in the application
- [ ] All 228 hardcoded color values in CSS modules replaced with CSS variables
- [ ] Inline styles in `src/app/page.tsx` updated to use CSS variables
- [ ] All pages (landing, auth, dashboard, forms) visually identical to pre-refactor state
- [ ] No color differences in buttons, borders, backgrounds, or text across the app
- [ ] Changing a color variable in `globals.css` updates that color throughout the entire application
