# Plan: Email Audit Log for Admin-Sent Emails

## Context
Admins can send emails to users via the admin users page, but there is no record kept. This plan adds an `email_logs` table to persist every email sent, shows users their received emails on the profile page, and gives admins a dedicated audit log view.

## Step 1 — Schema (`src/db/schema.ts`)

Add after `birdEntries`:

```ts
export const emailLogs = sqliteTable(
  "email_logs",
  {
    id: integer("id").primaryKey({ autoIncrement: true }),
    senderId: text("sender_id").notNull().references(() => user.id, { onDelete: "cascade" }),
    recipientId: text("recipient_id").notNull().references(() => user.id, { onDelete: "cascade" }),
    subject: text("subject").notNull(),
    message: text("message").notNull(),
    sentAt: integer("sent_at", { mode: "timestamp_ms" })
      .default(sql`(cast(unixepoch('subsecond') * 1000 as integer))`)
      .notNull(),
  },
  (table) => [
    index("email_logs_recipient_idx").on(table.recipientId),
    index("email_logs_sender_idx").on(table.senderId),
  ],
);

export type EmailLog = typeof emailLogs.$inferSelect;
export type NewEmailLog = typeof emailLogs.$inferInsert;
```

Update `userRelations` to add `sentEmails` and `receivedEmails` many-relations. Add `emailLogRelations` with two `one()` relations (sender/recipient) using `relationName` to distinguish them.

## Step 3 — DAL (`src/lib/dal/emailLogs.ts`)

Three functions:

```ts
insertEmailLogs(senderId, recipientIds[], subject, message): Promise<void>
// Batch-inserts one row per recipient ID.

getEmailsForUser(userId): Promise<EmailLogWithSender[]>
// Emails received by a user. Joins sender name. Orders by sentAt DESC.
// Type: EmailLog & { senderName: string }

getAllEmailLogs(recipientId?: string): Promise<EmailLogWithRecipient[]>
// All email logs for admin view, optionally filtered by recipientId.
// Uses aliasedTable(user, "sender_user") and aliasedTable(user, "recipient_user") for the double join.
// Type: EmailLog & { senderName: string; recipientName: string; recipientEmail: string }
```

Import `aliasedTable` from `drizzle-orm` for the double-join in `getAllEmailLogs`.

## Step 4 — Update `sendEmailAction` (`src/app/dashboard/admin/users/actions.ts`)

**Signature change:** `recipients: string[]` becomes `recipientIds: string[]` (user IDs, not emails).

**Logic change:**
1. Resolve emails: `db.select({ id, email }).from(userTable).where(inArray(userTable.id, recipientIds))`
2. Send via Resend using resolved emails
3. On success, call `insertEmailLogs(admin.id, recipientIds, subject, message)`
4. On Resend failure, return error without logging
